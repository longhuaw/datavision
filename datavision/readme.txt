     DataVision - 智能数据可视化低代码平台

     一、项目概述

     DataVision 是一个面向企业的智能数据可视化低代码平台，用户可以通过自然语言描述（NL2SQL）或拖拽配置快速生成数据
     图表和大屏看板。平台支持多数据源接入、实时数据刷新、看板发布分享，让非技术人员也能轻松构建专业的数据分析界面。

     二、解决的问题

     1. 数据分析门槛高：业务人员不懂SQL，每次做报表都要找开发，沟通成本高、响应慢
     2. 数据孤岛严重：企业数据分散在不同系统（MySQL、Excel、API），没有统一的可视化入口
     3. 看板复用性差：大部分BI工具导出的看板是静态的，无法动态交互和实时更新
     4. 大屏搭建复杂：做一块数据大屏需要前端+后端+设计多方协作，成本高昂

     三、核心功能模块

     模块1：数据源管理

     - 支持多种数据源接入：MySQL、PostgreSQL、ClickHouse、Excel/CSV上传、REST API
     - 数据源连接测试、元数据自动采集（表结构、字段信息）
     - 连接池管理与健康检查

     模块2：数据集管理

     - 基于数据源创建数据集（虚拟表/视图）
     - 支持SQL模式（写SQL查询）和拖拽模式（可视化关联）
     - 数据预览、字段别名、虚拟字段（计算字段）
     - 数据集定时刷新缓存

     模块3：图表工作台 ⭐核心亮点

     - NL2SQL自然语言生成图表：输入"近30天各品类销售额趋势"，自动生成SQL并渲染为折线图
     - 20+图表类型：折线图、柱状图、饼图、散点图、热力图、漏斗图、雷达图、桑基图、中国地图等
     - 图表样式自由配置（颜色、字体、图例、动画）
     - 图表联动和下钻

     模块4：看板设计器 ⭐核心亮点

     - 拖拽式画布布局，自由拖放图表组件
     - 看板尺寸自适应（支持大屏16:9、标准屏、移动端）
     - 组件间联动筛选（点击A图表，B图表联动过滤）
     - 看板主题模板库（暗黑、科技蓝、商务绿等）
     - 实时数据推送（WebSocket）

     模块5：发布与分享

     - 看板发布生成唯一URL，支持密码保护
     - 嵌入模式（iframe嵌入第三方系统）
     - 定时截图推送到企业微信/钉钉/邮件
     - 权限管理（查看/编辑/管理）

     模块6：AI助手 ⭐核心亮点

     - 智能图表推荐：根据数据特征自动建议最佳图表类型
     - 异常检测：自动识别数据中的异常波动并标注
     - 自动洞察：生成数据摘要和分析结论
     - 基于LLM的对话式数据分析

     模块7：系统管理

     - 用户与角色管理（RBAC）
     - 操作审计日志
     - 系统用量统计

     亮点1：NL2SQL 自然语言生成图表 🔥🔥🔥

     - 基于规则引擎 + 历史用户偏好学习

     亮点3：实时协作看板 🔥

     - WebSocket推送看板数据实时刷新

     - 基于统计方法（3-sigma、IQR）的异常点自动标注

     亮点5：一键部署与模板市场 🔥

     - Docker Compose 一键启动全套服务

     六、数据库设计（核心表）

     -- ==================== 系统管理 ====================
     -- 用户表
     users: id, username, password_hash, email, avatar, role, status, created_at, updated_at
     -- 角色表
     roles: id, name, description, permissions(JSON), created_at
     -- 操作日志表
     audit_logs: id, user_id, action, resource_type, resource_id, detail(JSON), ip, created_at

     -- ==================== 数据源管理 ====================
     -- 数据源配置表
     datasources: id, name, type(mysql|pgsql|clickhouse|api|excel),
                  config(JSON: host/port/db/user/password),
                  status, version, created_by, created_at, updated_at
     -- 数据源元数据缓存表
     datasource_metadata: id, datasource_id, tables_info(JSON), last_sync_at

     -- ==================== 数据集管理 ====================
     -- 数据集表
     datasets: id, name, description, datasource_id,
               sql_text, schema(JSON: 字段列表),
               cache_ttl, row_count, status,
               created_by, created_at, updated_at
     -- 数据集字段配置表
     dataset_columns: id, dataset_id, column_name, alias, data_type,
                      is_virtual, virtual_expr, is_dimension, is_metric,
                      format_config(JSON), sort_order

     -- ==================== 图表管理 ====================
     -- 图表配置表
     charts: id, name, description, chart_type, dataset_id,
             config(JSON: x轴/y轴/维度/度量/样式/颜色),
             query_config(JSON: 过滤条件/排序/分页),
             nl_prompt(NL2SQL的原始输入),  -- 🔥核心：自然语言输入
             thumbnail_url, created_by, version,
             is_template, category, created_at, updated_at
     -- 图表数据缓存表
     chart_cache: id, chart_id, data(JSON), cached_at, ttl

     -- ==================== 看板管理 ====================
     -- 看板表
     dashboards: id, title, description, theme,
                 width, height, is_published,
                 publish_url, password_protected, password_hash,
                 created_by, created_at, updated_at
     -- 看板布局组件表
     dashboard_components: id, dashboard_id, chart_id,
                           position(JSON: x/y/w/h),
                           z_index, config(JSON: 联动配置/刷新间隔),
                           sort_order

     -- ==================== AI相关 ====================
     -- NL查询历史表
     nl_query_history: id, user_id, prompt, generated_sql,
                       chart_type, is_valid, feedback, created_at
     -- 用户偏好表
     user_preferences: id, user_id, pref_type, pref_data(JSON)

     -- ==================== 发布分享 ====================
     -- 看板分享记录表
     share_records: id, dashboard_id, shared_by, share_type(link|embed|schedule),
                    config(JSON), token, expires_at, last_accessed_at
     -- 定时推送任务表
     scheduled_pushes: id, dashboard_id, channel(wechat|dingtalk|email),
                       cron_expr, config(JSON), enabled, last_run_at
